# Code map: Collab (apps/collab) and the sandbox agent (sandbox/agent)

Generated by `pnpm map` (scripts/code-map.mjs) from each file's exports and the first sentence of its first doc comment. Don't edit it by hand: improve the comment in the file, then run `pnpm map`. How the parts connect: [README.md](README.md).

## apps/collab/src

- `env.ts` Verifies the runner's service tokens (shared with api and runner). Exports: Env, loadEnv.
- `main.ts` Real-time document server (Hocuspocus 4).

## apps/collab/src/extensions

- `access.ts` Who may open a room document, and whether they may write to it. Exports: CollabContext, accessExtension.
- `persistence.ts` Postgres persistence, as proven in spike S3b (ADR 0005): - onChange appends each locally originated update to doc_updates, buffered and flushed every 100 ms. Exports: persistenceExtension.

## sandbox/agent/src

- `agent.ts` The sandbox agent (ADR 0003).
- `egress-policy.ts` Whether a resolved address is on the public internet. Exports: isPublicAddress, parseTarget, refusal.
- `egress.ts` A room's egress proxy (ADR 0007), in a container of its own on the room's network as "egress", while the room's owner allows package installs.
- `relay.ts` Package managers in the sandbox use http://127.0.0.1:3128 as their proxy: this relay. Exports: RELAY_PORT, startRelay.
- `rules.ts` True if a workspace-relative path (or anything under it) should not sync. Exports: TEMP_PREFIX, SYNC_MAX_BYTES, isIgnored, isIgnoredDirName, asText.
- `tunnel.ts` TCP connections to servers inside the sandbox, carried over the agent's stdio (spike S2: works with the container's network switched off). Exports: Tunnels, listeningPorts, watchPorts.
- `watcher.ts` Recursive watcher that skips ignored folders. Exports: TreeWatcher.
- `workspace.ts` The /workspace folder inside the sandbox, kept equal to the room's files. Exports: Inspection, Workspace.

## apps/api/src/ai

- `ai.config.ts` OLLAMA_URL (or the default) without a trailing slash, or null when it isn't an http(s) URL. Exports: DEFAULT_ANTHROPIC_MODEL, AiEnv, AiSettings, AiSetup, DEFAULT_OLLAMA_URL, ollamaUrl, LOCAL_HOSTS, resolveAiSetup, +1 more.
- `ai.controller.ts` Whether AI is set up, for the panel to show the chat or the setup help. Exports: AiController.
- `ai.service.ts` The configured model (if any), the per-person limit and usage counters. Exports: AiService.
- `complete.ts` The text to insert, from whatever the model said: no thinking, no code fences, nothing repeated from before or after the cursor, a few lines at most. Exports: COMPLETION, CURSOR, CompletionRequest, buildCompletionRequest, cleanCompletion, completionUsage, completionTimeoutMs, completionLimitMessage.
- `context.ts` Terminal output → plain text: no colour codes, and progress bars redrawn with \r keep only their last state. Exports: RunContext, SummaryContext, ContextParts, plainTerminalText, truncateMiddle, truncateStart, languageLabel, buildContextBlock.
- `prompts.ts` Keep the newest turns that fit in `maxChars`. Exports: systemPrompt, trimHistory, ModelRequest, buildModelRequest.
- `providers.ts` OpenAI itself or anything that speaks its API: OpenRouter, Groq, Gemini, Together, Ollama, LM Studio… Exports: StreamPiece, CompletionAnswer, AiProvider, AnthropicProvider, OpenAiCompatibleProvider, createProvider, describeAiError.
- `rate-limit.ts` Per-person AI request limit, shared by every API instance through Valkey. Exports: RateDecision, slidingWindow, WindowUsage, windowUsage, RateLimiter, rateLimitMessage.
- `summary.ts` "3 min ago": the server doesn't know the reader's time zone, so times are relative. Exports: ChatLine, ActivityRow, ago, formatChat, formatActivity.
- `usage.ts` Per-person usage, one Valkey hash per UTC day, kept a month. Exports: estimateTokens, estimateUsage, UsageTracker.
